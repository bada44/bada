RetroHub otomatik kod klasoru
=============================
Buraya koydugun dosyalar oyun acilirken OTOMATIK kurulur, elle secmen gerekmez.

  codes/gc/GALE01.txt        -> GameCube oyununun Game ID'si (6 harf/rakam) + .txt (Gecko kodu)
  codes/ps2/1A2B3C4D.pnach   -> PS2 oyununun CRC'si (8 hane) + .pnach

Gecko .txt formati: istege bagli "$Kod Adi" satiri, sonra "0XXXXXXX 0XXXXXXX" hex satirlari.
Oyun ID'sini/CRC'yi bilmen gerekmez: RetroHub oyun detayinda gosterir.
